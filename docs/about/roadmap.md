# Roadmap

What this site is, and what is coming. Dated so you can tell how stale it is.

## Now — 2026-08

- **Bulk Holds** — the full doc set, plus a deployment page.
- The five-page pattern, and a template a contributor can copy, in `docs/_template`.

The tool's source still lives in a private repository, so there is no public download link yet.
That is a known gap, not an oversight — see below.

## Next

- **Move the Bulk Holds source into this repository**, so the docs and the tool ship together and
  the download link on this site is real.
- **A Windows build and release pipeline**, so a released zip has a version number and a checksum.
- **Generated reference for the code**, once the source is here.

## Later

- More tools: web API endpoints, and tools built to be used directly by AI assistants.
- Tools that are not tied to one ILS live directly under `Tools`, rather than under a vendor.
