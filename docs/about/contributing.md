# Contributing

The full guide lives in `CONTRIBUTING.md` in the repository root. In short:

- Every tool gets the same five pages — tutorial, how-to, reference, explanation — plus one page
  for a single library's specifics. Copy `docs/_template/`.
- The four [Diátaxis](https://diataxis.fr) modes are never mixed on one page.
- Unpack every acronym on first use; archive every link you cite; stamp every claim about the
  ILS — the integrated library system — with what it was tested against.
- Run `bash scripts/gates.sh` before you commit.
